# clyven_backend_client

**English** | [简体中文](README.zh-CN.md)

The Serverpod client shared by every Clyven front-end. The code is generated by Serverpod from the server project; do not edit the generated files by hand. Regenerate it with:

```bash
cd server/clyven_backend_server
serverpod generate
```

Endpoints are called as `client.<endpoint>.<method>(...)`, for example `client.notification.list()`. See the [Serverpod documentation](https://docs.serverpod.dev) for details.
