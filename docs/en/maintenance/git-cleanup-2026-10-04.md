# Clyven / Glyphora Git Repository Cleanup Record

**English** | [简体中文](../../zh-CN/maintenance/git-cleanup-2026-10-04.md)

Date: 2026-10-04

## Goals

This cleanup targeted:

- one-off patch files
- temporary fix scripts
- local backup directories
- build output
- build reports
- development screenshots that nothing references
- temporary files that have since been absorbed into the real source and no longer need to be kept

It did not remove regular business code, database migrations, Serverpod generated code, tests, real configuration, real documentation, or platform source.

## 3. `.gitignore` updates

To keep these files out of the repository, the following rules were added or kept:

```gitignore
.clyven-patch-backup/
**/build/
/*.patch
/*.bak
apps/clyven_web/build/jaspr/
```

- `.clyven-patch-backup/`: ignore local patch backups
- `**/build/`: ignore the build directory of every nested project
- `/*.patch`: ignore temporary patches in the repository root
- `/*.bak`: ignore backup files in the repository root
- `apps/clyven_web/build/jaspr/`: explicitly ignore the Jaspr build

## 6. Size change

Comparing mirror repositories before and after the first cleanup:

```text
size-pack before:               3.04 MiB
size-pack after first cleanup:  3.33 MiB
```

The first pass did not save pack space noticeably, because:

- the deleted junk was small
- 232 commits were rewritten
- the pack and delta compression layout changed
- new commit and tree objects were generated

The second pass removed `apps/clyven_web/build/**` as well. The Jaspr build files visible in the large-file ranking alone exceed about 0.8 MB uncompressed, and the full history of that directory includes many smaller files.

The main benefit of the cleanup is therefore not repository size but:

- a cleaner Git history
- build artifacts no longer mixed into source history
- temporary patches no longer kept long term
- local backups no longer polluting the repository
- clearer collaboration and code review
